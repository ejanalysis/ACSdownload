# Package index

## All functions

- [`ACSdownload`](https://ejanalysis.github.io/ACSdownload/reference/ACSdownload.md)
  [`ACSdownload-package`](https://ejanalysis.github.io/ACSdownload/reference/ACSdownload.md)
  : Download American Community Survey (ACS) 5-year Data Tables from
  Census Bureau nationwide in bulk

- [`acsdefaultendyearhere`](https://ejanalysis.github.io/ACSdownload/reference/acsdefaultendyearhere.md)
  : The default end.year of 5yr ACS datasets this package uses in
  functions

- [`ejscreen_acs_tables`](https://ejanalysis.github.io/ACSdownload/reference/ejscreen_acs_tables.md)
  : tables needed for EJSCREEN ACS-based indicators as of EJSCREEN
  version 2.32 released 2024 and also for EJAM version 2.32.6.003
  released 11/2025

- [`fipstype_from_sumlevel()`](https://ejanalysis.github.io/ACSdownload/reference/fipstype_from_sumlevel.md)
  : Convert SUMLEVEL codes like "040" or "150" to fipstype strings like
  "state" or "blockgroup"

- [`get_acs_new()`](https://ejanalysis.github.io/ACSdownload/reference/get_acs_new.md)
  : Get full USA ACS data by table and fips (newer table-based summary
  file format)

- [`get_acs_old()`](https://ejanalysis.github.io/ACSdownload/reference/get_acs_old.md)
  : Older function to download Tables from American Community Survey
  (ACS) 5-year Summary File (before the acs2022 5yr data)

- [`sumlevel_from_fipstype()`](https://ejanalysis.github.io/ACSdownload/reference/sumlevel_from_fipstype.md)
  : Get the SUMLEVEL code like "040" or "150" from the fipstype string
  like "state" or "blockgroup"

- [`url_acs_table()`](https://ejanalysis.github.io/ACSdownload/reference/url_acs_table.md)
  :

  get URL(s) of ACS 5-year table(s) for general info or for FIPS code(s)
  (blockgroup or tract) at census.gov See
  [`EJAM::url_acs_table_info()`](https://public-environmental-data-partners.github.io/EJAM/reference/url_acs_table_info.html)
  for a more likely to be updated version
