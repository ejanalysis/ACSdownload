# Get first part of ACS zip file name.

Get the first part of the zipfile name for the ACS 5-year summary file
datafiles on the US Census Bureau FTP site.

## Usage

``` r
get.zipfile.prefix(end.year = acsdefaultendyearhere)
```

## Arguments

- end.year:

  Optional character, specifying last year of 5-year summary file data.
