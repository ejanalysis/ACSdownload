# list_files_ftp Attempt to get list of filenames on an FTP site

list_files_ftp Attempt to get list of filenames on an FTP site

## Usage

``` r
list_files_ftp(
  url,
  credentials = "",
  sleep = NA,
  sort = FALSE,
  verbose = FALSE
)
```

## Arguments

- url:

  URL

- credentials:

  empty

- sleep:

  NA

- sort:

  FALSE

- verbose:

  FALSE

## Value

file names
